Android

Install the Android app

Download for Android (APK, about 5 MB)
  1. Tap Download above, on your Android phone.
  2. When it finishes, tap the file to open it.
  3. If Android asks, allow your browser to install apps (Settings, then Install unknown apps), then tap Install.
  4. Open LoosenUp from your home screen.

This is a test build of LoosenUp, ready to try today. A Google Play listing can follow once a Play Console account is set up.

iPhone

Install the iPhone app

Install the iPhone app
  1. Open this page in Safari on your iPhone and tap Install the iPhone app.
  2. Tap Install when iOS asks. LoosenUp appears on your home screen.
  3. The first time only: Settings, General, VPN and Device Management, tap the developer app and tap Trust.

This is a test build for registered test iPhones. It renews every 7 days and keeps itself up to date in between. On any other iPhone, use the home screen app below.

iPhone and iPad

Add LoosenUp to your home screen

  1. Open loosenup.anchit-tandon.com in Safari.
  2. Tap the Share button.
  3. Tap Add to Home Screen, then Add.
  4. Open LoosenUp from your home screen. It works offline, with every feature.
