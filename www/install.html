Android

Install the Android app

Download for Android (APK, about 19 MB)
  1. Tap Download above, on your Android phone.
  2. When it finishes, tap the file to open it.
  3. If Android asks, allow your browser to install apps (Settings, then Install unknown apps), then tap Install.
  4. Open LoosenUp from your home screen.

This is a test build of LoosenUp, ready to try today. A Google Play listing can follow once a Play Console account is set up.

iPhone and iPad

Install LoosenUp on iPhone

  1. Tap Install LoosenUp above, in Safari on your iPhone.
  2. Tap Share, then Add to Home Screen, then Add.
  3. Open LoosenUp from your home screen. It opens full screen, works offline and has every feature.
Open LoosenUp in Safari

LoosenUp on iPhone installs from Safari, like adding any app to your home screen. An App Store version can follow later.

Install LoosenUp in three taps
